# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.

In short: be respectful and constructive. Harassment and discrimination are not
tolerated. Participation is expected to be professional and welcoming regardless
of background or experience level.

Report unacceptable behavior to the maintainers via a private GitHub Security
Advisory or direct contact. Maintainers may remove, edit, or reject
contributions and comments that violate this Code of Conduct.

The full text is available at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
